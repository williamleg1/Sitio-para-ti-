MINI APP — UN BOLETO PARA TI ❤️

1. Abre index.html para probarla.
2. Para compartirla por internet, sube toda esta carpeta a un hosting estático:
   - GitHub Pages
   - Netlify
   - Vercel
3. Mantén la carpeta assets junto a index.html.

La app ya incluye:
- Boleto digital animado.
- Galería con las 5 fotos proporcionadas.
- Tarjetas interactivas.
- Mini juego de 3 corazones.
- Sorpresa y carta final.
- Diseño responsive para celular.

Puedes editar los textos directamente en index.html.
